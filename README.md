# AnyQuestions
Add file with your questions, set timer and answer on it. For learning ^^

* Uses automatic property with private setter { get; private set; } for data encapsulation.

* Imports code from other files via using directive to access namespaces easily.

* Console app loads questions/answers from files, saves statistics, and remembers last used file path.

* Simple, lightweight, file-based solution for easy data management and user-friendly experience.
